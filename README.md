## ✅ Implemented Features

### Phase 1: Private LLM Assistant (Task 1.2)
- 🔁 **Local LLM Integration** with [Ollama](https://ollama.com)
- 💬 **Natural Language Q&A API**: Ask medical questions about ingested text
- 🧠 **In-memory Context Storage**: Keeps user-specific interactions via local memory

### Phase 2: Data Ingestion & Automation (Task 2.1)
- 🧾 **OCR/NLP pipeline** for lab reports & prescriptions (PDFs or images)
- 💾 **Automated ingestion & storage** in DHT (local memory for now)
- 🧠 **Summary Generation** using local LLM
- 🚨 **Abnormality Detection** using keyword-based alerts

## 🚀 Setup & Run Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/AbdulRahmanAlsakkaDitAkkad/health-ai-assistant.git
cd health-ai-assistant

2. Set Up Python Environment
python -m venv .venv
# Activate virtualenv
.venv\Scripts\activate    # on Windows
source .venv/bin/activate # on Linux/macOS

# Install dependencies
pip install -r requirements.txt

3. Install & Run Ollama (for local LLM)

Download from: https://ollama.com

Start Ollama and pull a model:

ollama run llama3

4. Run the API Server
uvicorn assistant.service.api:app --reload --port 8000


Then visit http://127.0.0.1:8000/docs
 to use the Swagger UI.

🧪 API Endpoints
📄 /ingest

Upload a PDF or image for OCR extraction.

Parameters: user_id, file

Returns: extracted_text, summary, alert: true/false

💬 /ask

Ask natural language questions based on ingested files.

Parameters: user_id, question

Returns: Answer generated by local LLM
